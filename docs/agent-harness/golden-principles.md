# Golden Principles

- Finance math must be explainable.
- Do not hide assumptions.
- Use explicit money types and currency fields.
- Never count pass-through money as profit.
- Prefer deterministic domain services for calculations.
- Keep controllers thin.
- Do not put business rules inside React components.
- Do not fetch government spreadsheets from frontend/mobile.
- Preserve auditability of financial decisions.
- Link to official sources for compliance decisions.
- Update docs when behavior changes.
