# Harness Observability

Agents and developers should make new operational behavior observable.

## Required For New Services

- Health endpoint.
- Readiness endpoint.
- Structured logs.
- Correlation IDs.
- Service-specific validation command.

## Required For Workers

- Import or job audit record.
- Retry visibility.
- Dead-letter handling plan.
- Failure runbook link.

## Required For Finance

- Calculation trace ID.
- Input snapshot.
- Output snapshot.
- Rounding assumptions.
