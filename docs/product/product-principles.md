# Product Principles

- Show safe money, not just gross revenue.
- Explain every finance result with visible inputs.
- Treat pass-through money separately from revenue and profit.
- Use driver-friendly language before accounting language.
- Keep app login separate from government systems.
- Link to official sources for compliance decisions.
- Prefer conservative warnings when source freshness is unknown.
- Make manual correction easy because real trucking data is messy.
- Preserve an audit trail for calculations, imports, and document changes.
- Build mobile-first; web is support/admin unless an issue says otherwise.
