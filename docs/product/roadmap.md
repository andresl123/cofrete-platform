# Roadmap

## M0 Repository Foundation

- Repository foundation and agent harness.
- Product, architecture, compliance, and runbook docs.
- Local infrastructure and CI guardrails.

## M1 Core Domain And APIs

- Core API scaffold.
- Finance worker scaffold.
- Data importer worker scaffold.
- Mobile app scaffold.
- Identity, driver, truck, and tax profile model.
- Versioned API and event contracts.

## M2 Finance Engine

- Freight and trip profitability APIs.
- Deterministic finance calculation engine.
- Reserve bucket and safe-withdrawal allocation.

## M3 Brazil Data And Compliance

- ANP diesel importer with fixtures.
- Toll and Vale-Pedagio classification.
- Compliance center data model and wording.
- Receivables and customer payment tracking.

## M4 Mobile MVP

- Mobile onboarding and new freight calculator screens.
- Reserve wallet and safe-withdrawal screens.
- Compliance center screens.

## M5 Dashboard, QA, And Demo

- Financial health dashboard.
- Smoke tests, demo seed, and validation flow.
- Optional web admin/backoffice dashboard.
- Launch checklist and risk register review.
