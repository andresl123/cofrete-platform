# User Personas

## Autonomous Driver

Owns or finances one truck and accepts freight from brokers, shippers, or platforms. Needs to know if a trip covers fuel, tolls, maintenance, tires, insurance, taxes, and family income.

Primary workflows:

- Enter new freight before accepting it.
- Compare gross freight against real trip cost.
- See safe personal withdrawal.
- Track RNTRC, insurance, IPVA, licensing, and document reminders.

## MEI Caminhoneiro Driver

Operates as a MEI Caminhoneiro and needs visibility into annual revenue limit usage, DAS reserve, and accountant review triggers.

Primary workflows:

- Track year-to-date invoiced amount.
- See warning bands near MEI limit.
- Keep tax profile metadata organized.

## Small Fleet Owner

Owns a small number of trucks and needs trip profitability, receivables, fuel assumptions, and document status across vehicles.

Primary workflows:

- Review driver/truck financial health.
- Monitor late receivables.
- Inspect compliance alerts.
- Use web admin/backoffice when available.

## Support/Admin User

Helps diagnose imports, demo data, calculation questions, and user setup issues without bypassing data privacy rules.

Primary workflows:

- Check import freshness.
- Review calculation inputs and outputs.
- Verify demo seed readiness.
