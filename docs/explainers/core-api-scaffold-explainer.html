ROU-209 / COF-005

Core API service scaffold

This task turns `core-api/` from a placeholder into a Java 21 Spring Boot service with Maven, Docker packaging, health checks, Flyway migration setup, PostgreSQL local profile wiring, tests, and documented module boundaries.

Done locally

What changed

  • Spring Boot app entrypoint and Maven build.
  • Actuator health endpoint at /actuator/health.
  • Security scaffold reserving /api/* for authenticated product APIs.
  • Flyway baseline migration for the core_api schema.
  • Local profile wired to Compose PostgreSQL defaults.
  • Harness check now requires this task-specific HTML explainer.

Why It Changed

Dependency ready

Local infrastructure exists

ROU-207 added Docker Compose PostgreSQL, RabbitMQ, and MinIO. Core API can now declare concrete local datasource wiring instead of placeholders only.

Backend base

Primary API service needed

Future profile, trip, finance, reserve, compliance, receivable, import, auth, and audit tickets need a runnable API service foundation.

Scope control

No product behavior yet

The scaffold reserves contract paths but does not implement finance, compliance, profile, trip, auth, or receivable behavior before dedicated issues define those details.

Module Boundaries

Profile

Drivers, trucks, trailers, and tax profiles.

Trip

Freights, trips, direct costs, tolls, and profitability snapshots.

Finance

Advisory product finance data and worker result surfaces.

Reserve

Reserve rules, wallets, allocations, and transactions.

Compliance

Advisory compliance metadata, documents, calendars, and official-source links.

Receivables

Customers, receivables, payments, and customer profitability.

Imports

Imported dataset status and import audit records.

Auth

Cofrete identity, sessions, authorization, and Spring Security.

Audit

User, admin, support, and internal-service audit logging.
