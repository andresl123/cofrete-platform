ROU-210 / COF-006

Finance Worker service scaffold

This task creates the Java 21 Spring Boot worker shell for asynchronous finance processing, wires RabbitMQ event boundaries, and keeps all deterministic finance algorithms out of scope for later dedicated issues.

Java 21 Spring Boot RabbitMQ Actuator health Scaffold only

What changed

Runtime

Added finance-worker/pom.xml, Spring Boot application entrypoint, local/test configuration, and a Dockerfile with a container health check.

Messaging

Added durable RabbitMQ exchange, queue, and binding configuration for the canonical finance events.

Boundary

Added listener and publisher stubs that validate event names while intentionally avoiding profitability or reserve allocation logic.

Canonical events

The worker uses event names from docs/architecture/event-contracts.md exactly.

Consumed

  • trip.recalculation.requested
  • reserve.allocation.requested

Published

  • trip.finance.recalculated

What did not change

  • No deterministic trip finance engine was implemented.
  • No reserve allocation algorithm was implemented.
  • No Core API or Data Importer Worker source was changed.
  • No Linear status, priority, labels, or comments were updated.

Affected files and areas

  • finance-worker/: Maven project, application code, AMQP configuration, event records, tests, Dockerfile, README, and service agent guide.
  • docker-compose.yml: optional services profile entry for running the worker against local RabbitMQ.
  • .env.example: added COFRETE_FINANCE_WORKER_PORT.
  • README.md and docs/architecture/repository-structure.md: updated repository status to mention the Finance Worker scaffold.

Finance and compliance caveats

  • Finance output remains advisory product software, not official legal, tax, accounting, insurance, or government guidance.
  • Monetary values stay as decimal strings with explicit currency in event payload records.
  • Toll reimbursement and Vale-Pedagio remain pass-through money and must not be counted as profit in later finance implementation.

Follow-up tasks unblocked

  • ROU-216 / COF-012: deterministic finance engine.
  • ROU-217 / COF-013: reserve allocation.
  • ROU-214 / COF-010: API and event contract hardening before deeper cross-service behavior.
