ROU-246 / COF-025 And ROU-218 / COF-014 Importers

Manually maintained derived summary. Canonical source of truth remains the Markdown docs and service code.

What Changed

  • Data Importer Worker now has synthetic ANP diesel and ANTT toll plaza/tariff fixtures with source URL, period/effective date, freshness, confidence, file hash, and import audit metadata.
  • Worker jobs publish canonical fuel-price.import.completed and toll-data.import.completed events using the exact architecture contract names.
  • Core API now persists import jobs, fuel prices, driver fuel reports, truck consumption profiles, toll plazas, and toll tariffs.
  • Core API serves GET /api/fuel-prices/latest, GET /api/fuel-prices/history, POST /api/fuel-prices/driver-report, GET /api/trucks/{truckId}/consumption-profile, POST /api/trips/{tripId}/fuel-estimate, source-backed POST /api/toll-estimates, and GET /api/toll-data/import-status.
  • Toll import status now returns the audit fields Linear asked for: source URL, source period, retrieval/completion timestamps, row count, file hash, parser error summary, freshness, confidence, and import audit ID.
  • Driver fuel reports are exposed as user-provided data with sourceType=driver_report, confidence=driver_confirmed, and freshnessStatus=CURRENT; they are not presented as official ANP data.

Why It Changed

Fuel and toll calculations need source-backed prices instead of placeholders. Responses now expose source, freshness, confidence, period/effective date, and import audit IDs so advisory estimates can show where assumptions came from.

Affected Areas

  • data-importer-worker/src/main/java/com/cofrete/dataimporter/anp and .../antt: fixture loaders and import jobs.
  • data-importer-worker/src/main/resources/fixtures: synthetic ANP and ANTT fixture files.
  • core-api/src/main/java/com/cofrete/coreapi/imports: import, fuel, and toll read models and endpoints.
  • core-api/src/main/java/com/cofrete/coreapi/profile: truck consumption profile read path.
  • core-api/src/main/java/com/cofrete/coreapi/trip: toll estimates now read imported toll tariffs, and fuel estimate lookup exposes owned trip context.
  • docs/architecture/data-model.md, core-api/README.md, and data-importer-worker/README.md: documentation aligned with the implemented persistence and importer behavior.

Validation

  • cd core-api && mvn -q validate test
  • python scripts/agent_harness_check.py

Compliance Notes

  • The committed fixture rows are synthetic and safe to commit; they are not official source extracts.
  • ANP fuel responses distinguish official-dataset-shaped fixture data from driver reports.
  • Toll estimates remain advisory and do not add production paid toll provider integration.
  • Vale-Pedagio and toll reimbursement remain pass-through money and must not count as profit.
