ROU-224 - COF-020 Build mobile compliance center screens

What changed

The mobile Riscos tab now loads and writes compliance metadata through Core API instead of showing static reference content.

  • Added typed mobile contracts for compliance profile, score, calendar, alerts, RNTRC, insurance policies, and documents.
  • Added API client methods for the documented compliance and document endpoints.
  • Added a compliance center screen with profile metrics, advisory alerts, calendar rows, insurance/document lists, editable metadata fields, and write actions.
  • Added tests for advisory wording, alert/list rendering, metadata saves, validation-style errors, and raw error suppression.

Why it changed

Drivers need one mobile place to organize RNTRC, insurance, and document metadata before accepting or running freight. The screen makes official-channel boundaries explicit and does not claim Cofrete updates ANTT, gov.br, SUSEP, insurer, DETRAN, SEFAZ, Receita Federal, or other official records.
