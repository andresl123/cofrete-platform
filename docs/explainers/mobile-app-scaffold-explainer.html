ROU-212 / COF-008 Mobile App Scaffold

This task creates the Expo TypeScript foundation for the Cofrete mobile app. It turns mobile-app/ from a placeholder directory into a runnable client with validation scripts, API client stubs, environment configuration, and React Navigation MVP route placeholders.

What Changed

  • Generated an Expo app using the blank TypeScript template.
  • Added a Cofrete mobile shell with React Navigation bottom tabs for dashboard, onboarding, freight, reserves, and compliance.
  • Added Core API endpoint constants and a typed client stub for future integration work.
  • Added TypeScript, ESLint, and Jest validation commands.
  • Updated mobile README and agent instructions with setup and validation commands.
  • Documented the required grill-with-docs review-and-fix loop for future Linear issue handoffs.

Risk Boundaries

  • Vale-Pedagio and toll reimbursement wording keeps pass-through money outside profit.
