ROU-225 Financial Health Dashboard

The mobile dashboard now renders a live advisory financial-health view instead of static reference content.

What changed

  • Mobile composes financial health, reserve wallets, overdue receivables, and compliance profile data.
  • The dashboard shows score, safe withdrawal, reserve coverage, receivable risk, compliance alerts, and source caveats.
  • Pass-through toll reimbursement and Vale-Pedagio stay visibly outside profit and safe withdrawal.
  • The mobile Core API client now has typed receivable contracts and a `GET /api/receivables?status=overdue` call.

  • mobile-app/src/MobileApp.tsx
  • mobile-app/src/api/client.ts
  • mobile-app/src/api/contracts.ts
