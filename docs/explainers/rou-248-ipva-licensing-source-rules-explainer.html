ROU-248 IPVA And Licensing Source Rules

Core API now exposes state/year/vehicle-type IPVA and licensing rules as source-backed records.

What changed

  • Added POST /api/source-rules/ipva for creating or updating reviewed IPVA/licensing metadata.
  • Added GET /api/source-rules/ipva to return a rule or an explicit MISSING status.
  • Extended ipva_rules with IPVA freshness, licensing source URL, licensing review timestamp, and licensing freshness.
  • Tests cover missing, current, and stale source review behavior.

Affected areas

  • core-api/src/main/java/com/cofrete/coreapi/profile/
  • core-api/src/main/resources/db/migration/V10__source_backed_tax_ipva_waiting_time_rules.sql
  • core-api/src/test/java/com/cofrete/coreapi/profile/ProfileEndpointTests.java
  • docs/architecture/api-contracts.md
  • docs/architecture/data-model.md

Validation

Risk boundary

Core does not fall back to a national hardcoded truck IPVA percentage. Missing source-backed state rules remain explicit.
