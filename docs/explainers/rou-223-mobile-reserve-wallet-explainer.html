ROU-223 - COF-019 Build mobile reserve wallet and safe withdrawal screens

What changed

The mobile Reservas tab now loads the Core API reserve wallet and financial health endpoints instead of showing static reference content.

  • Added typed mobile contracts for reserve buckets, reserve rules, reserve allocations, wallet transactions, and financial health.
  • Added API client methods for GET /api/reserve-wallets, POST /api/reserve-rules, POST /api/reserve-allocations, and GET /api/financial-health-score.
  • Added a reserve wallet screen with loading, empty, error, wallet balance, transaction history, starter rule, and allocation request states.
  • Kept safe personal withdrawal visually separate from required reserve buckets.
  • Added React Native tests for rendering, empty state, API error state, and reserve write actions.

Why it changed

ROU-223 turns reserve and safe withdrawal contracts into a usable mobile surface. The UI keeps reserves as virtual planning envelopes and avoids implying bank movement or guaranteed spendable money.
