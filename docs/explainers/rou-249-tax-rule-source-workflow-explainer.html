ROU-249 Tax Rule Source Workflow

MEI Caminhoneiro and Pessoa Fisica tax assumptions now live in source-backed yearly records instead of hardcoded application constants.

What changed

  • Added POST /api/source-rules/tax-years for yearly tax rule upserts.
  • Added GET /api/source-rules/tax-years for regime/year lookup with explicit missing status.
  • Extended tax_rule_years with freshness and a configurable cargo-transport taxable percentage for Pessoa Fisica planning.
  • Responses label tax outputs as planning estimates and route drivers to Receita Federal/accountant review.
