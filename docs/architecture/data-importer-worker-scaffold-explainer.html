ROU-211 / COF-007

Data Importer Worker service scaffold

This task creates the Java 21 Spring Boot worker shell for source-data imports, wires scheduler and RabbitMQ publisher boundaries, and keeps real ANP and toll-provider integrations out of scope until dedicated importer issues define source handling.

Java 21 Spring Boot RabbitMQ Synthetic fixture Scaffold only

What changed

Runtime

Added data-importer-worker/pom.xml, Spring Boot application entrypoint, local/test configuration, and a Dockerfile with a container health check.

Imports

Added synthetic ANP diesel fixture loading and import job stubs that carry source, freshness, confidence, audit ID, and correlation ID fields.

Messaging

Added RabbitMQ publisher stubs for fuel-price.import.completed and toll-data.import.completed.

Canonical events

The worker uses event names from docs/architecture/event-contracts.md exactly.

Published

  • fuel-price.import.completed
  • toll-data.import.completed

What did not change

  • No production ANP downloader or parser was added.
  • No production paid toll provider integration was added.
  • No normalized database tables or Core API import endpoints were added.
  • No Linear status, priority, labels, or comments were updated.

Affected files and areas

  • data-importer-worker/: Maven project, application code, AMQP configuration, event records, scheduler/import stubs, tests, Dockerfile, README, and service agent guide.
  • data-importer-worker/src/main/resources/fixtures/anp-diesel-prices-synthetic.csv: synthetic ANP diesel fixture for scaffold validation.
  • .env.example: added the worker port and scheduler toggle.
  • README.md, docs/README.md, and docs/architecture/repository-structure.md: updated repository status and service structure.
  • scripts/agent_harness_check.py: requires this task-specific explainer.

Finance and compliance caveats

  • Imported fuel and toll data must expose source, freshness, confidence, and import audit metadata.
  • Driver-facing behavior must degrade to advisory or unknown when source data is stale, failed, or ambiguous.
  • Cofrete remains advisory product software, not an official government, legal, tax, accounting, insurance, or toll certification channel.
