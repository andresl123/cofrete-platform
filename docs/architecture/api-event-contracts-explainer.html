What Changed

Contracts Are Now Implementation-Ready

The API contract now documents the MVP public interfaces by method, path, purpose, request shape, response shape, and error cases. It covers driver and truck profile, tax profile, trip-driven freight decisions, reserves, fuel, tolls, compliance, customers, and receivables.

The event contract now defines canonical event names, producers, consumers, routing keys, idempotency keys, ordering assumptions, retry behavior, schemas, and examples.

API Scope

HTTP Contract Areas

  • /api/drivers, /api/trucks, and /api/tax-profile own app-maintained identity, vehicle, and tax-planning metadata.
  • /api/trips owns the MVP freight decision workflow and profitability estimate handoff.
  • /api/reserve-*, fuel, toll, compliance, customer, and receivable endpoints define the semantics later service work must follow.

Guardrails

Finance And Compliance Caveats

  • Profitability, reserves, safe withdrawal, fuel, toll, tax, insurance, RNTRC, CIOT, IPVA, licensing, and waiting-time outputs are advisory unless backed by documented official source metadata and freshness timestamps.
  • Toll reimbursement and Vale-Pedagio are pass-through money and must not count as profit.
  • ANP fuel data must keep source period, retrieval time, freshness, and confidence visible.
  • Compliance endpoints distinguish app-maintained metadata from authoritative records and must link drivers to official channels where relevant.
